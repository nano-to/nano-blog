# Working Notes

Use this directory for temporary research notes. The actual digest draft lives
in `articles/nano-digest-template.md` so it can be rendered and reviewed with
the normal blog build. Its `hidden: true` frontmatter keeps it out of public
indexes, tags, RSS, and the sitemap until it is ready.

Use the normal article frontmatter when a draft is ready for review:

```text
- title: Nano Digest: September 2026
- date: 09-30-2026
- tags: Digest, Nano
- free: true
- author: @nano2dev
-----
Issue content in Markdown.
```
